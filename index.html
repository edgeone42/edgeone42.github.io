👤 About Me
Hi, I'm Taylor Torres — a developer based in Walton, Nebraska, USA. I'm passionate about serverless architectures and edge computing, with a particular focus on making powerful backend tooling accessible on constrained, distributed runtimes.

My recent work includes openlistnext, a project that ports Go-based file-listing infrastructure to JS/TS so it can run natively on platforms like Cloudflare Workers — no traditional server required. I also contribute to open-source cloud email infrastructure built on Cloudflare's ecosystem.

Always exploring the boundary between what's possible and what's practical at the edge.
